# Анализатор текстовых файлов

-------------------------------

## Описание

Программа, подсчитывающая количество каждого слова, встречающегося в текстовом файле, и создающая `CSV` таблицу с частотами слов.
Колонки итоговой таблицы:
1. Слово.
2. Частота.
3. Частота (в %).
CSV файл должен быть упорядочен по убыванию частоты, то есть самые частые слова
должны идти в начале. Разделителями считать все символы кроме букв и цифр.


## Запуск
    $path_to_your_prog input.exe output.csv
    1. $path_to_your_prog - путь до исполняемого файла
    2. input.txt - путь до входного файла
    3. output.csv - путь, по которому будет расположена итоговая таблица частот
