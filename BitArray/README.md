# Битовый массив

-------------------


## Описание
Библиотечная реализация битового массива на языке `C++`.

Битовый массив (битовое множество) - это массив, компактно хранящий биты и позволяющий удобно ими оперировать. В этой задаче реализован битовый массив переменного размера (в отличие от std::bitset).

Каждая функция подробно задокументирована.

Каждая функция покрыта тестами из специализированной библиотеки [Google Test Framework](http://code.google.com/p/googletest/).

## Функционал
Интерфейс библиотеки подробно описан и задокументирован в [заголовочном файле](https://github.com/winuwind/CPP-projects/tree/main/BitArray/src/BitArray.h).
